# Подкидной дурак ♠

Игра в браузере на русском языке с двумя режимами: **против компьютера** или **вдвоём на одном устройстве**. Не требует регистрации, серверной части или установки библиотек.

## Играть

После успешного развёртывания GitHub Pages: https://ponomarevkk.github.io/game_test/

GitHub Actions: https://github.com/ponomarevkk/game_test/actions

Если адрес недоступен, проверьте Settings → Pages → Build and deployment → Source: GitHub Actions. Workflow включён и должен создавать публикацию.

## Правила

- Колода из 36 карт (6 — туз); каждому по 6 карт.
- Первый ход делает обладатель младшего козыря.
- Бить карту можно старшей той же масти или козырем. Козырь бьётся только старшим козырем.
- Подкидывать можно достоинства, которые есть на столе. Максимум — 6 атакующих карт или число карт защищавшегося в начале раунда, если оно меньше 6.
- Если защитник отбился, атакует он. Если защитник взял карты, атакует тот же игрок.
- Карты добирают до шести, сначала атакующий.
- После окончания колоды первый игрок, избавившийся от карт, выигрывает; одновременный выход — ничья.

## Режимы

В режиме с компьютером бот самостоятельно делает ходы; в локальном режиме двое передают устройство друг другу и раскрывают свою руку только после передачи. **Онлайн-режима по сети нет.**

## Как запустить локально

Вся игра находится в одном файле `index.html`. Откройте этот файл двойным нажатием — установка и сборка не нужны.

## Реализация

HTML, CSS и JavaScript без внешних зависимостей. Workflow `.github/workflows/pages.yml` публикует сайт на GitHub Pages.
