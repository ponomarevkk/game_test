# Подкидной дурак ♠

Браузерная карточная игра в подкидного дурака на русском языке. Без регистрации, рекламы и сторонних библиотек.

## Игровые режимы

- **Против компьютера** — вы играете против автоматического соперника.
- **Вдвоём** — два человека играют за одним экраном, с приватной передачей хода и скрытыми картами.

> Второй режим — **локальный**, не онлайн-мультиплеер через интернет.

## Правила

36 карт (6–туз), по 6 карт в руки, случайно выбранный козырь. Начинает игрок с младшим козырем. Защищающийся отбивается старшей картой той же масти или козырем; козырь бьётся старшим козырем. Подкидывать можно только достоинства, которые уже есть на столе, не более 6 карт и не больше числа карт, которое было у защищающегося в начале хода. После взятия атакующий ходит снова, после отбоя ход переходит к бывшему защитнику. Атакующий добирает карты первым. После окончания колоды первый оставшийся без карт выигрывает; если оба избавились одновременно — ничья.

## Запуск

Для локальной игры нужен только веб-сервер (чтобы работали ES-модули):

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000 . Никакого `npm install` не требуется.

## Тесты

```bash
npm test
```

Игровые правила находятся в `game.mjs`, интерфейс — в `app.mjs`, оформление — в `style.css`.
